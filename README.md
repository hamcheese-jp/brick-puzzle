# ブリックパズル3D

見本の3D完成品をよく見て、ブロックを組み立てて同じものを作るパズルゲームです。

- **遊ぶ:** GitHub Pages のURLを開くだけ（`index.html`）
- 全100ステージ（どうぶつ・しょくぶつ・たてもの・のりもの など50種類）
- フリースペースで自由に作って保存・SNS投稿
- 2D版: `2d.html`

## 操作
- ピースを選んで台やブロックをクリック／タップ（上の面→積む、横の面→くっつける、下の面→ぶら下げる）
- ドラッグで視点回転、ホイール／2本指でズーム
- 右クリックか「外す」でブロックを外す、Rキーで向きを変える
