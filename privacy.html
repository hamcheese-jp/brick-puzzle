プライバシーポリシー

ブリックパズル3D（以下「本ゲーム」）　制定日：2026年11月19日

本ゲームの運営者（GitHub アカウント：hamcheese-jp。以下「運営者」）は、本ゲームを遊ぶみなさんの情報を大切に扱います。本ポリシーでは、本ゲームでどのような情報を扱うか、どう使うかを説明します。

1. 運営者が集める情報

運営者は、名前・メールアドレス・住所などの個人を特定できる情報を、本ゲームを通じて集めていません。アカウント登録もありません。

2. 端末に保存される情報

本ゲームは、次の情報をお使いのブラウザの中（ローカルストレージ）に保存します。これらは運営者のサーバーには送られません。

  • ステージのクリア状況とクリアタイム
  • フリースペースで作った作品と、そのサムネイル画像
  • BGM のオン・オフなどの設定

ブラウザのサイトデータを消すと、これらの情報も消えます。タイトル画面の「データを書き出す」で、ご自身でバックアップできます。

3. 広告について

本ゲームでは、第三者配信の広告サービス（Google AdSense／H5 Games Ads）を利用する場合があります。広告配信事業者は、利用者の興味に応じた広告を表示するために、Cookie などの技術を使って、本サイトやほかのサイトへのアクセス情報を利用することがあります。

  • Google による広告での Cookie の使い方は、Google の広告に関するポリシーをご覧ください。
  • パーソナライズ広告は、Google の広告設定から無効にできます。
  • 広告配信事業者による情報の扱いは、Google のプライバシーポリシーに従います。

本ゲームは子どもも遊ぶことを想定しています。広告は、子ども向けに配慮した設定で配信するよう努めます。

4. アクセス解析について

現在、本ゲームではアクセス解析ツールを使っていません。今後使うことになった場合は、本ポリシーを更新してお知らせします。

5. SNS への投稿について

「SNSに投稿」機能を使うと、作品の画像と文章を、お使いの端末の共有機能や各 SNS の投稿画面に渡します。投稿するかどうか、何を投稿するかは利用者ご自身が決めます。投稿した内容の扱いは、各 SNS の規約とプライバシーポリシーに従います。

6. 外部サービス

本ゲームは、3D 表示のためのプログラム（three.js）を外部の配信サービス（cdnjs、jsDelivr）から読み込んでいます。読み込みの際、通常のウェブ閲覧と同じように、お使いの IP アドレスなどがそれらのサービスに送られます。また、本サイトは GitHub Pages で公開しています。

7. 免責事項

本ゲームの内容には十分注意していますが、正確性や安全性を保証するものではありません。本ゲームの利用によって生じた損害について、運営者は責任を負いかねます。本ゲームからリンクしている外部サイトの内容についても、責任を負いかねます。

8. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更したときは、このページでお知らせします。

9. お問い合わせ

本ゲームや本ポリシーについてのお問い合わせは、GitHub の Issues（お問い合わせ窓口）からお願いします。投稿の内容は公開されるため、個人情報は書かないでください。
